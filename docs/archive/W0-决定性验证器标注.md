# W0：10 个任务的决定性验证器标注

> 2026-11-20。判据只有一条：**存在一条可执行命令，真值来自交付物之外的客观数据/测试**，
> 且它能对「格式齐全但结论/数字错」的稿子判红。只是「要素齐不齐」的不算。
> 依据：W0 v2 探针的 L2 读数 1/10（`reports/w0-formalize-v2-20261120-124826.json`）。

| # | 任务 | 有决定性验证器？ | 真值在哪 / 为什么没有 |
|---|---|---|---|
| A | 该不该做 agent 创业方向 | ❌ | 决策真假依赖市场与判断，本地无真值；只能查要素 |

| J | 离“死了仍完成”差什么 + 验收命令 | ⚠️ 半 | 命令本身可跑（决定性），但“差什么”是判断 |

**比例：严格判「有」= 1/10（10%）；把「半」也算上 = 1+3/10，但「半」不能支撑内环**——
内环要求在无模型的情况下判对错，半可判等于不可判。

## 结论

1. 这批任务**不是**内环的适用域：8 个判断题、1 个半可判、1 个全可判。
2. 按 kill criteria（判定型覆盖 <40%），不启动内环；先把目标域换成“真值在本地（测试/账本/测量）”的工程任务。
3. 唯一合格的任务 I 用来做第一片内环切片：确定性渲染 + 外置判定权 + 红先测试。

## 任务 I 的切片口径

- 交付物：`{"tokens": int, "rejects": int, "redone_count": int}`。
- 生成：`sa2/loop/cost_page.py: render(run_dir)`，只读 `readings.json`，同输入必同输出（0 次模型调用）。
- 判定：`sa2/core/cost_check.py: check(page, run_dir)`，逐项与账本比对；缺字段、数字错都判红。
- 红先：测试里先用“结构齐全但 token 差 1”的稿子证明验证器会红，再用渲染结果证明会绿。
