# ASI 全形态蓝图：一支永不闭幕的科研军团

> 状态：**蓝图**（目标形态，不是当前实现）。当前仓库是它的一具骨架，差距见 §9。
> 用途：回答"它长什么样、怎么运转、能做出什么"。数量级是设计目标，未实测。
> 关联：`docs/archive/ASI-方案-v1.md`（判定层规格，已归档）、`docs/ASI-方案-v2.md`（四层与自举）。

## 0. 定界

**一句话：ASI 是一支 24 小时不闭幕的科研军团——上千个短命执行者、几百个独立判官、一个活的资产库，围绕"能判真假"的靶场高速迭代，规模随算力线性放大。**

它不是什么：不是一个更聪明的模型；不是一个开会的公司；不是一套更严的流程；不是一万个 agent 投票。

## 1. 军团编制

| 层 | 数量级 | 寿命 | 干什么 | 谁判 |
|---|---|---|---|---|
| L0 元层（人） | 3–5 人 | 常驻 | 定域、定红线、批不可逆动作 | 人 |
| L1 战略层 | ~10 agent | 周 | 选区、选题、分预算、决定今天打哪三个方向 | 读数（账本曲线） |
| L2 目标层 | 100–1,000 个 WorkNode 并发 | 小时–天 | 每个节点一个目标 + 一套判据 | 节点判据 |
| L3 执行层 | 10³–10⁴ 短命 agent/轮 | 分钟–小时 | 出候选、深挖、修错、写代码 | 不判，只产出 |
| L4 判定层 | 候选数 × 2（k=2） | 分钟 | 独立判真假、交叉验证、造反例 | 外部内核 + 独立证据 |
| L5 资产层 | 连续增长 | 永久 | 技能库、判据库、失败样本库、定理库 | 入库需验收 |

扇出：每个目标约 10 个子节点，每个节点约 16 条候选，每条候选 2 个独立判官。这是"放大镜"的实际含义——**每一层只放大 10–20 倍，逐层聚焦，不是一次铺开一万个**。

## 2. 一天怎么转（24 小时时间线）

- **00:00 结算**：账本roll出昨夜曲线——哪条路线通过率涨了、哪条死了；预算按"不确定性"重分（高不确定的保底，低不确定的按读数给增量）。
- **00:30 选举**：战略层从失败样本库和指标曲线里选出今天要打的 **3 个方向**，各自展开一棵 WorkNode 树。不投票，按读数排序，前 3 进入。
- **01:00–08:00 大并行**：1,000+ 执行 agent 在 3 方向 × 10 节点 × 16 候选上跑；判官同时判；通过的进深挖，失败的立刻进失败样本库。
- **08:00 第一刀**：通过率低于 10% 的分支整体杀掉，预算转给有信号的。**这一刀是全系统最重要的动作**——它把宽度变成深度。
- **08:00–20:00 深挖与证伪**：幸存分支各派 3 条**独立证据路径**的 agent 去证明或证伪，不许共享证据；判官独立判。
- **20:00 固化**：今天通过的东西写成三样——可执行工具（进技能库）、更强的检查器（进判据库，带版本与来源样本）、测试或定理（进对应库）。
- **22:00 审计**：抽 1% 的通过样本做独立复核，算出今天的**放行错误率**；这个数决定明天判据往哪改。
- **24:00 收账**：所有状态回到 append-only 账本，可回放、可分叉、可合并；进程可死，状态不死。

## 3. 变强的节奏与读数

| 周期 | 发生什么 | 读数 |
|---|---|---|
| 一天 | 一轮并行 + 一刀 + 一次固化 | 新增判据数、放行错误率 |
| 一周 | 判据库升 N 版；技能库 +N 工具 | 抓错率（升）、单位成功成本（降） |
| 一月 | 换一个域：同骨架换验证器 | 新域达标轮数（应逐月变少） |
| 一年 | 它开始自己选区、自己改判据 | 人工介入率（降）、无人介入最长步数（升） |

变强不是靠"更多 agent"，而是靠这三个数同时在动：**判据抓错率升、复用率升、每正确解搜索节点数降**。

## 4. 它能做出人类组织做不到的什么

| 不可比项 | 人类组织 | 这支军团 |
|---|---|---|
| 并行假设数 | 一个团队同时追 ~10 条 | 10³ 条同时追，每条独立证据 |
| 记忆 | 会忘、会离职、经验随人走 | 全部进库，不遗忘、不流失 |
| 失败处置 | 复盘靠人，多数失败被丢掉 | 每个失败都成样本，直接变判据 |
| 跨域迁移 | 靠个别通才，速度以年计 | 骨架不变，换验证器即迁移，速度以周计 |

产出形态是具体的：通过的测试与证明、可复现的实验报告、新算法、更强的判据、新的测试集。每一样都带完整证据链，可回放。

## 5. 四件骨架（缺一件形态就塌）

1. **判定锚在外部**：最终裁定落在系统改不动的地方（编译器、证明内核、隐藏测试）；模型写的规则只做路由。
2. **判据冻结**：节点立项即冻结判据；要改 = 新建节点。生成方永远不持有判据。
3. **账本唯一真源**：状态只能从 append-only 事件重放；进程死、机器换、被接管，都从断点继续。
4. **数据三分**：train / dev / test 互斥；挖反例只碰 dev，否决只看盲测；没有三分，自举就是自欺。

## 6. 双环与放大镜落在哪里

- **内环（当天）**：执行 → 判 → 改，分钟到小时级；就是上面 01:00–20:00 的主循环。
- **外环（每周）**：换域、换判据、换预算分配；它改的是内环的"规则"，不是它的"答案"。
- **放大镜**：每层扇出 10–20 倍，逐层把不通过的分支剪掉；**宽度只在第一层出现，之后全是深度**。

## 7. 资源与人的位置

资源：算力、预算、数据、API 全部走资源账本；按不确定性分档，超阈值走审批，池不可超支。

人只做三件事：**定域**（哪些领域值得打）、**定红线**（哪些动作不可逆、必须批）、**审计**（抽 1% 复核放行错误率）。其余全部自动——人不是每个回路里的一员。

## 8. 免疫清单（每种失效都有对应机制）

| 失效 | 机制 |
|---|---|
| 自证循环（自己判自己） | 判定锚外部 + 生成方不持有判据 |
| 同质化（一万份相同意见） | 独立性记账：不同证据/工具/判据才算独立 |
| 过拟合对抗集 | 数据三分 + 盲测集否决 |
| 路线僵化 | 不确定性预算 + 每日一刀淘汰 |
| 幻觉传播 | 判定方独立取证 + 证据链可回放 |
| 崩溃清零 | 账本重放 + 租约 + 接管 |

## 9. 三个里程碑（可判读数）

| 里程碑 | 形态 | 判红读数 |
|---|---|---|
| M-A 单域跑通 | 一个 L0 域内，判据能自己变强 | 抓错率从 16.7% 到 ≥60%，盲测不降 |
| M-B 跨域迁移 | 换验证器不换骨架，新域复用旧资产 | 新域达标所需轮数逐次减少 |
| M-C 自主选区 | 它自己决定下一个域、自己改判据 | 人工介入率持续下降，无人介入步数持续上升 |

**差距**：当前仓库有 M-A 的骨架（状态机、账本、预算、判定探针），没有自举、没有跨域、没有自主选区。

## 10. 为什么这个形态适合 AI

AI 的独特优势是四件：**可复制**（一个 agent 的经验瞬间复制给一万个）、**不疲劳**、**记忆完美**、**可回放可分叉**。人类组织的四个硬约束——带宽、信任、遗忘、离职——AI 一个都没有。

所以形态必须是"种群 + 资产库 + 外部锚"，而不是"公司 + 层级 + 会议"：层级是为信任设计的，会议是为带宽设计的，这两样对 AI 是纯开销。

## 11. 未定项

- 10³–10⁴ agent/轮 的实际并发与去重效果未测，可能远低于设计值；
- 一天时间线里的耗时是设计假设，没有真实运行数据；
- M-C（自主选区）没有可执行判据，只有方向；
- 判据自举在真实域上的增益仍是零读数。
